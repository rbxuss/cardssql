Cómo funciona

SQLCards es una app de flashcards para aprender SQL reconociendo lo que hace cada consulta. Ves la consulta, piensas qué hace, y pulsas Revelar para comprobar.

Niveles

  • Básico — consultas sueltas, sin JOINs ni subconsultas.
  • Medio — JOINs (1-2), GROUP BY, HAVING, subconsultas simples.
  • Experto — CTEs, window functions, subconsultas correlacionadas, 3+ JOINs.

Diccionarios

  • Conceptos — glosario de cláusulas y funciones SQL individuales.
  • Casos — problemas típicos de negocio con una o varias soluciones SQL.

Atajos de teclado

  • Espacio — revelar respuesta
  • 1 / 2 / 3 — calificar
  • ← / → — navegar entre cartas

Compartir

Como todo vive en un único archivo index.html, puedes enviarlo por correo, subirlo a GitHub Pages, Netlify o Vercel, o compartir tu mazo personalizado con el botón "Copiar link compartible".
